# Welcome to MemoBox

This is my personal portfolio website built with Next.js and modern web technologies. Here you'll find my latest blogs, vlogs, and projects.

## What is MemoBox?

MemoBox is a personal platform where I share my thoughts, experiences, and creative work. It's designed to be a modern, fast, and beautiful space for my content.

## Features

- **Blogs**: Articles and thoughts on various topics
- **Vlogs**: Video content and tutorials
- **Admin Panel**: Easy content management
- **Modern Design**: Built with Tailwind CSS and Next.js
